# 当前功能与实现边界

本清单对应当前发布源码。运行时地址和账户来自操作者本地保险库，市场规则及费率来自 Nado 公开接口；仓库不附带个人钱包、密码、交易日志或正式资金测试报告。

## 入口与能力

| 入口 | 已实现 | 范围与边界 |
| --- | --- | --- |
| `/accounts` | 创建和导入 EVM 钱包、HD 派生、加密备份、恢复验证、公开地址导出 | 密钥在本地浏览器保险库；拉取代码不会迁移钱包 |
| `/` | 行情、钱包状态、订单及资金操作界面 | 支持项目配置的测试网和 Ink 主网；签名与发送受当前网络、账户和额度校验约束 |
| `/connect` | 指定钱包通过 WalletConnect 连接官网、一次用户名签名授权 | Ink 主网；一次会话只绑定一个钱包，用户名授权不等于交易或代币授权 |
| 独立官网执行器 | 可恢复的连接/用户名流程、范围分片、2–6 个 Edge/Chrome 实例、单成员恢复 | 使用专用浏览器配置；需要操作者解锁和核实条款；不是批量交易引擎 |
| `/funds` | 1 USDT0 的 1→2→3→1 循环、统一付 Gas、费用与耗时报告 | 当前执行入口为三钱包一次测试；多批交接仍是规划接口 |
| `/trade-test` | 前 10 个钱包只读预检、资金库补款、全部到账后逐户一次开平仓、恢复和报告 | 手动启动保存的批次；不会自动开始下一批或反复开仓补成交量 |

## 钱包互转与统一 Gas

Ink USDT0 转账使用 EIP-3009：持币钱包在本地签署指定金额、接收人、授权序号和有效期，资金库提交链上交易并支付 Ink ETH。USDT0 直接从来源钱包到目标钱包，来源钱包不需要为这条授权路径持有 ETH。

页面在签名前核对链、钱包、余额和预算，按顺序保存授权、原始交易及哈希后广播；支持原交易核对、跨标签页执行锁、暂停恢复及 CSV/JSON 导出。实际 Gas 由回执执行费和 L1 费用计算，参考报价不等于最终收费。

批次交接具备一一对应规划、费用比较和 `queueHandoffAfterTrading` 事件接口。目前该接口只保存待检查计划，尚未连接自动提现和下一批交易，不会收到一个事件就自动发送钱包资金。详见[资金交接说明](runbook/funds-handoff.zh-CN.md)。

## 首批自动充值与交易流程

1. **只读预检。** 检查前 10 个钱包的身份、默认子账户及逐仓仓位、全市场挂单、余额和候选市场；计算取整后的名义金额、保证金、费用预留及差额。
2. **保存计划。** 固定资金库、各账户专属充值地址、额度和费用预算。保存只写本地记录，不签名、不付款。
3. **自动补款。** 操作者启动后，1 号链上资金库将 Ink USDT0 直接转入各账户专属 Nado 地址，其他账户不需要为这一步准备 ETH。余额足够的账户跳过；目标按 0.1U 向上取整，有缺口时按至少 5U 处理，多出的余额仍是本金。
4. **核实到账。** 要求匹配原链上转账和授权事件、唯一的新 Nado 入账事件，以及账户可用余额。预算和等待到账采用轻量余额查询；短暂陈旧数据有限重读，身份错误直接停止，不因超时或暂停再付一笔。
5. **再次预检。** 所有补款核实后，检查账户和市场当前状态。实际开仓前再次读取价格及仓位，不把旧预览当成有效行情。
6. **逐户开平仓。** 首选 EURUSD-PERP、GBPUSD-PERP、USDJPY-PERP，可选 SPY-PERP 作为备选。SPY 为永续合约，不是股票现货。各钱包买卖方向交替，向公开盘口挂单，不指定测试钱包互为对手方。
7. **归档和导出。** 核对实际成交、费用及余额变化，生成可导出的本批报告；待归档数据不会被当成零成交。

当前交易参数是每账户一次约 100 USDT0 名义开仓、20 倍初始逐仓杠杆；数量及保证金按市场精度取整，所需可用余额高于单纯 5U 保证金。完整开仓和平仓的累计成交量约为 200U，但部分成交、未成交和价格变化会改变实际结果。

开仓为 Post-only 限价，最多等待 60 秒；部分成交后撤余单，只处理已成交仓位。平仓为 Reduce-only IOC，价格保护 0.10%，最多三次尝试。没有成交不会追补新开仓。当前默认不设置累计损耗停机线；价格保护不等于固定亏损上限，流动性或网络异常时可能仍有仓位需要处理。市场条件不符会跳过该候选市场或暂停，不保证每个钱包都成交。

## 进度、恢复与费用口径

- **进度可见：** 当前阶段、钱包、动作、最近更新时间，充值发送/链上确认/到账计数，开平仓订单详情及最近 300 条执行事件。
- **到账时间分开：** 链上区块时间、Nado 入账事件时间、本地核验时间分别记录；本地核验耗时可能含断网或暂停，不代表链上真实速度。
- **付款防重复：** 持久化固定授权序号和原哈希；恢复先查询原交易，只能沿用原交易字节，不新建付款绕过未知结果。相同批次和跨标签页并发受到本地执行锁限制。
- **订单防重复：** 每钱包最多一个开仓意图；未知提交结果先查原摘要，收尾只处理可核实的仓位。停止按钮不再开启新仓，并尝试撤单和平仓。
- **费用统计：** 充值本金、链上 Gas、归档订单费用和权益净减少分开显示。权益变化已经含盈亏及相关费用，不能再把订单费重复加上去。
- **报告脱敏：** 导出不含私钥、授权签名或可重放交易字节；公开地址、交易哈希和金额仍属于操作者的运行数据，不应直接提交到公开仓库。

本地日志和保险库都在操作者设备。页面刷新或关闭会中断浏览器执行；重新打开不会自动续跑，须解锁并选择原批次恢复。执行锁只覆盖同一浏览器来源，不能阻止其他钱包工具或外部脚本操作同一账户。详见[自动交易测试操作说明](runbook/trade-test.zh-CN.md)。

## 尚未实现或不作保证

- Nado 自动提现、交易结束后资金自动回链、下一组钱包自动充值和交易的完整循环。
- 10,000 个钱包连续交易、自动轮转或服务器后台无人值守运行。
- 多账户充值流水线、批量链上分发合约、自动跨链、交易所自动提现。
- 保证成交、固定 Gas、固定到账秒数、固定交易损耗或收益。
- 更改 Nado 后台的测试名单、公开成交量口径、积分或奖励规则；本地 `internal-test` 标记仅用于报告分类。

## 发布、配置和验证

完整仓库包含应用源码、依赖锁文件、Windows 启停与安装脚本、配置模板、测试和操作文档。个人 `.env.local`、`private-data/`、`browser-profiles/`、`.local/`、保险库备份、真实钱包清单、日志、测试截图和构建缓存由忽略规则排除，原本机文件无需删除。钱包与进度迁移请另看[迁移指南](MIGRATION.zh-CN.md)。

从 [README](../README.md) 完成安装与启动。自动化验证使用模拟节点、一次性无资金钱包或只读接口；通过测试不表示所有真实钱包、所有市场或完整周级流程均已验收。可运行：

```powershell
pnpm redaction:selftest
pnpm redaction:gate
pnpm typecheck
pnpm lint
pnpm test
pnpm test:registration
pnpm test:registration:browser
```

资金和交易页面的隔离浏览器测试配置分别是 `apps/console/playwright.funds.config.ts` 与 `apps/console/playwright.trade-test.config.ts`，只使用模拟网络及独立浏览器数据。
